# Backend and API

This folder is the backend/API work area for the teammates implementing the service. The current project contains the React/Vite frontend only; no backend server code has been added yet.

Before adding the server, agree on API routes and JSON request/response formats with the frontend owner. The frontend integration notes are in the repository root `README.md`.

Keep credentials and local environment files out of Git. Share required variable names in a `.env.example` file without real secret values.
